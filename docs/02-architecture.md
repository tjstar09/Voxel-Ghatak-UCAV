## Voxel core

- `V_STEP=0.2`, `BoxGeometry(0.2)` shared
- `registerVoxel(subKey,gx,gy,gz,matKey)` + `registerVoxelSym` for mirroring
- Grouped as `[subKey][matKey]` -> `InstancedMesh` per group with dummy Object3D
- Sub-assemblies: nose, intakeSpine, coreFuselage, wingLeft/Right, elevonsLeft/Right, engine, weaponsBay
- Extra doors: `bayDoorLeft/Right` hinged at x=∓7
- Telemetry: `totalVoxelCount + doors + envVoxelCount`
