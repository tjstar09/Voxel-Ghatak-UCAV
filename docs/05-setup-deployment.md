# Setup, Development & Deployment

## Prerequisites

- Node.js 22 (Pages runners deprecated Node 20 — see commit 1604a78)
- npm, Git, Gemini API key for AI features

## Setup

```bash
git clone https://github.com/tjstar09/Voxel-Ghatak-UCAV.git
cd Voxel-Ghatak-UCAV
npm install
cp .env.example .env.local
# edit GEMINI_API_KEY=... APP_URL=...
npm run dev
```

Open http://localhost:3000

## Scripts (`package.json`)

- `dev`: vite --port=3000 --host=0.0.0.0
- `build`: vite build (out dist/)
- `preview`: vite preview
- `clean`: rm -rf dist server.js
- `lint`: tsc --noEmit
