# Voxel-Ghatak-UCAV — Overview & Quickstart

> Interactive 3D voxel model of DRDO Ghatak UCAV, India's autonomous stealth flying-wing combat jet.

- **Repo:** https://github.com/tjstar09/Voxel-Ghatak-UCAV
- **Live Demo:** https://tjstar09.github.io/Voxel-Ghatak-UCAV/
- **Stack:** Vite 6 + React 19 + Three.js + Tailwind CSS 4 + TypeScript
- **Entry:** `index.html` (Three.js app) + `src/main.tsx` + `src/App.tsx`
- **Branch:** `main`, auto-deployed via `deploy-pages.yml`

## What it is

- High-density voxel Ghatak with ~8,500-10,000 voxels (`V_STEP=0.2`)
- OrbitControls + auto-rotation, 60+ FPS via InstancedMesh per sub-assembly/material
- Twin SAAW smart glide bombs, animated bay doors, Kaveri dry turbofan with shielded 2D nozzle
- Voxel aircraft carrier with ski-jump, ocean swells, mountain ring, drifting clouds, land runway island, wingmen, target bunker
- HUD with Views / Actions / Flight controls + telemetry
- Web Audio synthesized missile launch sound (no assets)

## Quickstart

```bash
npm install
# set GEMINI_API_KEY in .env.local (see .env.example)
npm run dev   # vite --port=3000 --host=0.0.0.0
npm run build # vite build -> dist/
npm run preview
npm run lint  # tsc --noEmit
```

- `index.html` (93KB) — full app: scene, lighting, materials, voxel builder, environment, animation loop, HUD wiring
