# Auto-Sync — GitHub Actions to Notion on merge to main

Yes — implemented via `sync-notion-docs.yml`.

## How it works

1. Trigger: `on: push: branches: [main]` (i.e. PR merged to main) + `workflow_dispatch`
2. Job `sync-docs` runs ubuntu-latest:
   - checkout with full history
   - setup-node 22
   - `node scripts/sync-notion-docs.mjs` generates `docs/*.md` from `package.json`, `index.html`, `git log`
   - Upserts to Notion via Notion API (`NOTION_API_KEY`, `NOTION_PARENT_PAGE_ID` secrets) — matches pages by title, updates content or creates if missing
   - Commits back `docs/*.md` if changed (with `[skip ci]` to avoid loops)
3. Existing `deploy-pages.yml` still deploys site; new workflow only syncs docs.

## Required repo secrets

- `NOTION_API_KEY`: Notion internal integration token (Settings -> Integrations -> New -> copy token, share parent page with integration)
- `NOTION_PARENT_PAGE_ID`: `3d7cee05-b4c6-805e-bba9-f17ecf12c0d4` (Voxel-Ghatak-UCAV page)

Set in GitHub -> repo Settings -> Secrets -> Actions -> New.

## Loop protection

- Commit from bot uses `[skip ci]` + `if: github.actor != 'github-actions[bot]'`
- Notion API calls are idempotent by title match
- Manual run via Actions tab -> Run workflow
